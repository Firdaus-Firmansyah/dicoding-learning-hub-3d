Custom Event

Mendefinisikan & Membangkitkan Event Kustom Sendiri di JavaScript

📌 Konsep Pembuatan Custom Event

Langkah-langkah membangkitkan Custom Event:

// 1. Buat instance event kustom baru
const changeCaption = new Event('changeCaption');

// 2. Daftarkan event listener untuk menangani event kustom tersebut
tombol.addEventListener('changeCaption', customEventHandler);

// 3. Bangkitkan (trigger/fire) event menggunakan dispatchEvent()
tombol.dispatchEvent(changeCaption);
