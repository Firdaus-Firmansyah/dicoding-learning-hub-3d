Method Prompt pada BOM

Menerima Input Teks & Angka Langsung dari Pengguna

📌 1. Penggunaan `prompt()`

Method prompt() menampilkan kotak dialog yang meminta pengguna untuk memasukkan teks. Nilai yang dikembalikan selalu bertipe string (atau null jika dibatalkan). 

// 1. Input teks biasa
const pesan = prompt('Masukkan pesan sesukamu:');

// 2. Input angka dengan konversi Number()
const angka = Number(prompt('Masukkan sebuah angka:'));

// 3. Input dengan nilai default (placeholder)
const nama = prompt('Silakan masukkan nama Anda!', 'John Doe');
