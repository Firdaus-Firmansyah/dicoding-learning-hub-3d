🌐 Modul 01

Cara Memanggil Anggota BOM

Memahami Objek Global Window, Anggota BOM, dan Function Shadowing

📌 1. Konsep Browser Object Model (BOM)

BOM adalah sekumpulan objek di browser yang memungkinkan JavaScript berinteraksi dengan jendela browser. Objek utama di BOM adalah window. 

// Cara 1: Memanggil secara eksplisit melalui objek window
window.alert('Hello dari window.alert!');

// Cara 2: Memanggil secara langsung (karena window adalah Global Scope)
alert('Hello dari alert langsung!');

⚠️ 2. Fenomena Function Shadowing (Mendefinisikan Ulang Alert)

Jika kita membuat fungsi kustom dengan nama alert, fungsi tersebut akan menimpa (shadow) method bawaan window.alert di scope lokal. 

function customAlert(nama) {
  console.log('Hati-hati, ' + nama);
}
