Method Alert pada BOM

Menampilkan Modal Dialog Pemberitahuan ke Pengguna

📌 1. Apa itu `alert()`?

Method alert() digunakan untuk menampilkan kotak dialog (pop-up modal) sederhana berisi pesan dan tombol OK. Eksekusi JavaScript akan dijeda (blocking) sampai pengguna menekan tombol OK. 

// 1. Alert dengan teks string langsung
alert('Halo, user!');

// 2. Alert menggunakan nilai dari variabel
const message = 'Selamat belajar Front-End Web di Dicoding!';
alert(message);
