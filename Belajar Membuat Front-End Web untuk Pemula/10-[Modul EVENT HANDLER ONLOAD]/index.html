Event Handler Onload

Mengeksekusi Kode Saat Seluruh Halaman Selesai Dimuat

📌 Penerapan `document.body.onload` / `window.onload`

Event load / onload akan terpicu secara otomatis ketika seluruh dokumen HTML, stylesheet, dan gambar selesai dimuat. 

function welcome() {
  alert('Sim salabim muncullah elemen-elemen HTML!');
  const contents = document.querySelector('.contents');
  contents.removeAttribute('hidden');
}

// Menetapkan event onload pada body dokumen
document.body.onload = welcome;

✨ Halaman dan seluruh elemen DOM telah siap digunakan!
