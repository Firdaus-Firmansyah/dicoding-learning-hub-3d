⚖️ 2. Perbedaan Kritis: `onclick` vs `addEventListener`

❌ Property Handler (onclick)

Hanya menampung 1 fungsi. Fungsi kedua akan menimpa fungsi pertama.

btn.onclick = aksiA;
btn.onclick = aksiB; // aksiA tertimpa!

✅ addEventListener()

Bisa mendaftarkan banyak listener sekaligus untuk satu event.

btn.addEventListener('click', aksiA);
btn.addEventListener('click', aksiB); // Keduanya jalan!
