🎯 Modul 17

Event onInput, onFocus, dan onBlur

Menghitung Sisa Karakter Real-time & Interaktivitas Form

📋 Form Input dengan Live Counter

💡 Tiga Event Utama yang Bekerja:
  • focus: Munculkan notifikasi sisa karakter saat kursor aktif di input.
  • input: Hitung sisa karakter secara real-time saat pengguna mengetik/menghapus.
  • blur: Sembunyikan kembali notifikasi saat kursor keluar dari input.
