Membuat Elemen HTML Baru

Membuat Node Elemen Dinamis Menggunakan document.createElement()

📝 Sintaks & Manipulasi Konten

// 1. Membuat elemen paragraf baru
const newElement = document.createElement('p');

// 2. Mengisi teks murni (plain text)
newElement.innerText = 'Selamat datang ke HTML ini :)';

// 3. Mengisi struktur HTML berformat
newElement.innerHTML = '<b>Selamat datang</b> ke HTML kosong ini :)';

// 4. Membuat elemen gambar & mengatur atributnya
const newImg = document.createElement('img');
newImg.setAttribute('src', 'https://picsum.photos/300/180');
newImg.setAttribute('alt', 'Contoh Gambar Dinamis');
