Pengenalan Event & Inline Handler

Menerapkan Event Handler Langsung pada Atribut HTML

📌 1. Penerapan Inline Event Handler

Inline event handler ditulis langsung sebagai atribut pada tag HTML (misal: onclick, onload):

<!-- Tombol dengan event onclick inline -->
<button onclick="alert('Halo! Apa Kabar?')">
  Tekan Aku (Inline Alert)
</button>

<!-- Memanggil fungsi JS dari atribut onclick -->
<button onclick="handleClickInline()">
  Tekan Aku (Panggil Function)
</button>
⚠️ Catatan Best Practice: Inline event handler mudah digunakan untuk demo cepat, namun pada aplikasi nyata sebaiknya dihindari demi memisahkan struktur (HTML) dan logika (JavaScript) serta mencegah masalah Separation of Concerns.
